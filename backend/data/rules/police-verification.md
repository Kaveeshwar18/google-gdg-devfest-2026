## Why verification happens and its modes

Police verification confirms the details an applicant gives, so that a passport does not reach the wrong person. Verification is done in one of two modes:

- **Pre-passport issuance:** police verify before the passport is printed.
- **Post-passport issuance:** the passport is issued first and police verify afterwards.

The passport office decides the mode for each application, and pre-issuance verification applies in most cases. There are exceptions for government employees:

- With an Identity Certificate (Annexure A), the passport can be issued without verification.
- With a No Objection Certificate (Annexure G), verification happens after issue.
- With a Prior Intimation letter (Annexure H), verification happens before issue.

Tatkaal applications are verified after the passport is issued. Processing times for each mode are published in the Passport Seva citizen charter.

## Addresses the police check

Proof is needed only for the present address. The application must still list every address from the previous year, so that police can verify them. For residents of Jammu and Kashmir, verification is done at both the permanent and the present address. For residents of Nagaland, verification is done before issue.

## When verification is pending for a long time

The official FAQ covers an applicant still waiting for verification months after applying. If the passport has not arrived, the applicant should visit the passport office concerned. The Passport Seva home page also has a Feedback / Grievance link for registering a complaint. No fixed number of days counts as overdue for every case. The expected time depends on the verification mode and is set out in the citizen charter.

## When the police report is adverse

If the file status shows an adverse police report, the applicant should contact the passport office to learn the reason. After the applicant clarifies, re-verification can be requested where needed. The passport office needs a clear report from that re-verification. Once it receives a clear report, the file moves on towards issue.

## Minors and police verification

Minors (under 18, passport valid for 5 years) generally do not need police verification when all of these hold:

- Either or both parents hold a valid passport.
- One parent's name appears in the other parent's passport as spouse.
- Both parents consent through Annexure D.

Applicants aged 15 to 18 can instead choose a 10-year passport, which needs verification before issue. The passport office makes the final decision on the mode. If a parent has an adverse report or a criminal background, the minor can be issued a passport under Tatkaal, subject to approval by the competent authority.

## Court cases and past name changes

An applicant with a criminal case pending in any court can be issued a passport if they attach the court's written permission to travel abroad. Normally a short-validity passport, valid for one year, is issued under GSR 570(E) of 25 August 1993, along with any conditions in the court order. An applicant who has changed their name in the past should attach the name-change documents listed in the document advisory with the application.
